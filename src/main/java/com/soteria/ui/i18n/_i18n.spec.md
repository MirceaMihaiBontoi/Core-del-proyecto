# UI i18n Package (`com.soteria.ui.i18n`)

## Responsibility

Bridges **persisted language choice** (profile and onboarding) to **`java.util.Locale`** so JavaFX and `ResourceBundle` load the correct `messages*.properties` bundle.

Canonical language names and fuzzy matching (`es`, `español`, BCP-47 tags, etc.) live in **`OnboardingLanguageCatalog`**. This package only maps those canonical labels to JVM locales.

## Structure

```
i18n/
├── UiLocales.java    # Locale resolution from preferred language string
└── _i18n.spec.md     # This document
```

## Class: `UiLocales`

Utility class (non-instantiable). Single entry point:

| Method | Role |
|---|---|
| `fromPreferredLanguage(String preferred)` | Calls `OnboardingLanguageCatalog.matchOrDefault(preferred)`, then maps the result to a `Locale`. |

If `preferred` is null, blank, or not recognized, `matchOrDefault` returns **English**; `UiLocales` then returns `Locale.ENGLISH`.

## Canonical label → `Locale`

Values come from `OnboardingLanguageCatalog` after `matchOrDefault` (English display names).

| Canonical (catalog) | `Locale` |
|---|---|
| English | `Locale.ENGLISH` |
| Spanish | `Locale.forLanguageTag("es")` |
| French | `Locale.FRENCH` |
| German | `Locale.GERMAN` |
| Italian | `Locale.ITALIAN` |
| Portuguese | `Locale.forLanguageTag("pt")` |
| Romanian | `Locale.forLanguageTag("ro")` |
| Valencian | `Locale.forLanguageTag("ca-ES-valencia")` |
| Chinese | `Locale.SIMPLIFIED_CHINESE` |
| Russian | `Locale.forLanguageTag("ru")` |
| Arabic | `Locale.forLanguageTag("ar")` |
| Japanese | `Locale.JAPANESE` |

## Resource bundles (`classpath:i18n/`)

Base name **`messages`**. Default bundle is `messages.properties` (English). Locale-specific suffixes are chosen by `ResourceBundle` from the `Locale` above; for example `Locale.FRENCH` selects `messages_fr.properties`.

Bundles shipped under `src/main/resources/i18n/`:

- `messages.properties`
- `messages_es.properties`
- `messages_fr.properties`
- `messages_de.properties`

## How the pieces connect

```
Profile.preferredLanguage()  or  onboarding language pick
            │
            ▼
OnboardingLanguageCatalog.matchOrDefault(...)
            │
            ▼
UiLocales.fromPreferredLanguage(...)
            │
            ▼
Locale  ──→  LocalizationService.setLocale(...) / FX ResourceBundle lookup
```

Callers:

- **`MainApp`**: initial locale from saved profile.
- **`OnboardingController`**: applies locale when the user picks a language during onboarding.
- **`ChatController`**: syncs localization when loading the profile or when the language changes in settings.
